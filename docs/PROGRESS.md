## Обнаруженные исходники

- HTML: `index.html` — общий каркас без секций страниц.

- Референсы 11 страниц, состояний и UI Kit — в `files/`; 2 технических задания в DOCX.

## Принятые технические решения

- Не менять стек: HTML/SCSS/нативный JS; допускается уже находящийся в проекте Swiper.
- Продукт — B2B; ни цен, ни корзины.
- Модальных окон заявок нет. Успех отправки — только после реального подтверждения сервера.
- Архитектура должна позволять замену демонстрационного содержимого данными из MODX.
