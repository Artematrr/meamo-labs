# MEAMO — поэтапные задания для Codex (без сборщиков и зависимостей)

**Порядок:** 1А → 1Б → 2 → 3 → 4 → 5. В каждой новой сессии передавай **только один** блок промпта. `AGENTS.md` в корне — обязательные ограничения; `docs/PAGE_MAP.md` — готовая декомпозиция; `docs/PROGRESS.md` — текущее состояние.

**Не забывать:** это статическая вёрстка в существующем HTML/SCSS/JS. Не создавать `package.json`, npm, Nunjucks, `templates/`, `data/`, `qa/`, `tools/`, тестовые скрипты и дополнительные конфигурации. Для каждого этапа разрешены только текущие HTML-файлы в корне, SCSS, `scripts/main.js`, скомпилированный CSS (если есть `sass`), обновление `docs/PROGRESS.md`. Небольшое повторение HTML шапки/футера допустимо; общие стили и обработчики — один раз.
